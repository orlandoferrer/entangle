# entangle
Keep dot files in sync

There’s a tradition in software engineering that software starts simple to solve a single problem and then grows in complexity over time and becomes bloated, just like the alternatives you were trying to avoid. I’m pretty sure this is the  case here. We’ll see where this goes. 

Background
Years ago I used to spend significant time customizing every aspect of my computer (back when having a single computer was the norm and having two or more was a luxury). Over time, I stopped spending so much time customizing and became more of a defaults guy. Now I have a handful of old PCs that I want to leverage for different things, but also realized that it’s much practical to use dot files. I’m aware of several existing packages to handle that, but they look too complex for my needs, and I have some opinions on how it should work. Of course now I’m doomed to start a “simple” thing that might turn into a worse implementation of the existing packages, but I’m willing to live with that.
